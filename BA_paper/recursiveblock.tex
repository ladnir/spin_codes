In \sectionref{sec:block}, the blocks of each matrix we considered were each sampled independently and uniformly at random. Instead, we could generate them recursively using our block construction, i.e., each block would itself be made up of smaller blocks, etc. Since our block construction has high enough minimum distance, each block built recursively would serve as a reasonable enough surrogate for a truly random matrix on the one hand while simultaneously boosting our capability for parallelization on the other.
