# Riffle BCHPerm-TransposeBitShuffle-SplitState t=128 s=32

**Status: promising conditional coset exploration.** This branch tests whether
the SplitState inner can recover performance by halving its state from 64 to
32 bits. The conditional regular-occupation calculation still reaches the 9%
distance target. The smaller state does not yet make SplitState competitive
with FieldCheckpoint (K=8).

## Inner constituent

One epoch has 128 input and output bits. Its state has 32 bits. The fixed maps
have types

\[
A:\mathbb F_2^{32}\to\mathbb F_2^{128},
\qquad
B:\mathbb F_2^{128}\to\mathbb F_2^{32},
\qquad BA=0.
\]

For epoch input \(X\) and state \(Q\), the encoder outputs \(X+A(Q)\).
It applies \(B\) to this output, combines the result with \(Q\), and applies
the epoch's fixed nonzero field multiplier to every nonzero next state.

The scaled nested ensemble uses 64 auxiliary coordinates. The columns used to
construct \(A\) have weight 7 before two accumulator layers. The 96 mixed
columns of \(B\) have weight 3, and its remaining 32 coordinates are parity
coordinates.

## Constituent existence gate

The exact expected spectrum of the nested ensemble gives 0.001031 expected
nonzero words of weight at most 19. The probability that all 96 mixed columns
of \(B\) are distinct is 0.396407. A union bound therefore proves that some
pair in the ensemble simultaneously has these properties:

1. the code generated by \(A\) has minimum distance at least 20; and
2. all mixed columns of \(B\) are distinct.

The resulting lower bound on the probability of both events is 0.395376.
This is an existence result for the ensemble. No fixed pair has been generated
or audited.

For a zero incoming state, distinct columns make inputs of weights one, two,
and three activate the next state with probability one. The averaged
nonactivation upper bounds for input weights four, six, and eight are
\(2.15\mathbin{\cdot}10^{-5}\), \(1.16\mathbin{\cdot}10^{-6}\), and
\(1.56\mathbin{\cdot}10^{-7}\), respectively.

## Distance calculation at 9%

The calculation uses a modeled binary [256,128] outer spectrum, output length
\(2^{21}\), and target distance 188743. It covers all 8192 regular outer
occupations.

The density envelope is loose at one active block. Replacing that term with
the exact modeled one-active calculation gives 80.50445 bits of aggregate
floating-point margin. The next limiting occupations are three and two active
blocks, with 94.873 and 123.366 bits of pointwise margin.

This positive result assumes the averaged affine-coset moment used by the
combined-coset envelope. The ordinary fixed-coset estimate fails badly: at
1024 active blocks its exponent is +36331.41 bits. Under the combined-coset
envelope, the corresponding exponent is -64225.03 bits. Proving the averaged
coset statement is therefore essential.

## Performance implication

The current logical estimate is 9.3657 XORs per output bit. The 64-bit-state,
256-bit-epoch SplitState estimate is 10.6147, so halving the state saves about
12%. FieldCheckpoint (K=8) is estimated at 4.1226 XORs per output bit.
Thus the smaller state does not recover the cost gap under the current
accounting. No wall-clock implementation of this exact constituent exists.

## Scope

This branch does not provide an end-to-end certificate. The following items
remain open:

- prove the averaged affine-coset moment for a fixed constituent;
- generate and audit a fixed [128,32] nested constituent;
- handle outer configurations containing the all-one word;
- replace the modeled outer spectrum; and
- rerun the final calculation with outward-rounded arithmetic.

The active construction remains FieldCheckpoint (K=8).
