# Goal 03: finite distance frontier

## Question

How large a minimum distance can the current construction certify at binary
length (2{,}097{,}408), and which proof relaxation should be tightened next?

## Target

1. Locate the frontier of the Goal 02 moment proof.
2. Replace the worst small-support relaxation by an exact finite count.
3. Resweep every relevant weight and packet-support profile.
4. Report the certified distance separately from the proof-method ceiling and
   from any estimate of the true distance.

## Pass condition

The goal passes if an exact small-support calculation increases the certified
distance without changing the construction and identifies the next profile
that prevents further composition.
