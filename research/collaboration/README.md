# SPIN collaboration hub

This directory coordinates parallel work on SPIN codes. The originating chat
is the integration owner. Workstream chats produce bounded artifacts; they do
not merge or rename shared objects independently.

Read these files before starting work:

1. `SPIN_NAMING.md`;
2. `RIFFLE_NEXT_WORK_ROADMAP.md`;
3. the frozen construction's `MAIN_CODE_FREEZE.md`;
4. `collaboration/INTEGRATION_CONTRACT.md`;
5. the assigned workstream brief.

The first wave has four workstreams:

- `implementation_cleanup`;
- `paper_architecture`;
- `finite_asymptotic_theory`;
- `linear_time_audit`.

Each workstream owns a distinct directory under `workstreams/`. The integration
owner reviews and merges results after the first wave completes.
