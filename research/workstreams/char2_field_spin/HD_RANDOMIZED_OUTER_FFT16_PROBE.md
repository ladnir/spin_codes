# FFT16 tiles: a bounded quiet-distance probe

Replacing eight FFT8 tiles with four FFT16 tiles preserves the required
packet identities and improves the tested quiet upper bounds. The gain
does not certify any of the three requested middle-range classes.

This note studies a construction variant, not a change to the current
encoder. The outer code, coordinate scalars, regional routing, packet
width 64, and state dimension four remain unchanged. No native code,
performance experiment, remote run, or commit is involved.

## The proposed packet maps

The coefficient field is AES GF256, embedded in GF65536. Addition of
node labels means bitwise XOR. For i<16, let b_i be the normalized novel
polynomial basis: b_i has degree i and is the product of the normalized
subspace polynomials selected by the set bits of i. For an aligned
offset a, define the 16-by-16 evaluation matrix

    E_a[u,i] = b_i(a+u),  0<=u,i<16.

The four input tiles have offsets a=0,16,32,48. Their output nodes have
offsets a+64. The packet matrices are

    F = blockdiag_a(E_(a+64) E_a^(-1)),
    A = vertical concatenation of the first four columns of E_(a+64),
    C = horizontal concatenation of the last four rows of E_a^(-1).

Thus C sums coefficients 12 through 15 across the four input polynomials.
The state uses the low-degree basis b_0,...,b_3. Let T be translation by
64 on this four-dimensional polynomial space. The encoder still emits
Y=FX+AQ and then updates Q_next=MQ+CX.

The maps satisfy

    F^2=I,  T^2=I,  FA=AT,  CF=TC,  CA=0.

Translation by 64 is an involution and preserves polynomials of degree
below four, proving the first three identities. For i<4,
b_(12+i)=b_12 b_i. Translating b_12 changes it by a polynomial of degree
at most eight. Multiplication by a translated b_i therefore gives degree
below 12. The highest four novel coefficients consequently transform by
the same T, proving CF=TC. Finally, every injected polynomial has degree
below four, so its highest four coefficients vanish.

Every square minor of a tile feedthrough is nonsingular. Indeed, a
nonzero degree-below-16 polynomial cannot vanish at 16 distinct nodes.
A vanishing a-by-a minor would impose 16-a input zeros and a disjoint
output zeros, contradicting that root bound.

A generates an MDS[64,4,61] code because it evaluates a degree-below-four
polynomial at 64 distinct output nodes. C is an MDS parity check matrix.
To see the latter, write the local Lagrange numerator at input node u as
(L_4(X)+L_4(a))/(X+u), where L_4 vanishes on the 16-node input subspace.
Its four highest coefficients are a common invertible triangular
transform of 1,u,u^2,u^3. The normalization and conversion to the novel
basis are also common to all tiles. Hence C is an invertible row
transform of the four-row Vandermonde matrix on nodes 0 through 63.

These arguments hold over GF65536 as well. The helper additionally checks
the displayed identities and the Vandermonde representation exactly over
GF256.

## The same quiet moment, with larger tiles

Fix a potential subset S of a packet. The outer comparison samples X_S
uniformly from GF65536^S and sets all other input coordinates to zero.
For 0<z<=1, define

    K_S(z) = E_X[1[CX=0] z^wt(FX)],
    T_S(z) = E_X[z^wt(FX)].

A quiet word has zero state before every emitted packet. Thus the first
32767 packets use K_S; the final packet uses T_S because its successor
state is free. These artificial uniform amplitudes are part of the proof,
not an additional encoder randomizer.

Write g for tile width, either eight or 16. In one tile, let a count
potential inputs and let v count selected output zeros. The output
constraints have rank min(a,v). Their residual polynomial space has
dimension d=max(a-v,0), and its highest-four coefficient image has rank
min(4,d). This follows by factoring the required roots: multiplication by
the root polynomial shifts the degree filtration by g-d.

Residual lines from different tiles are distinct. When d=1, the monic
residual polynomial has g-1 roots in one coset of the binary subspace
generated by the tile directions and 64. Since g-1 is odd, the sum of
these roots belongs to the same coset. That sum is the next-to-leading
coefficient. Different tiles occupy different cosets, so their normalized
highest-four coefficient vectors cannot be equal.

For residual dimensions d_l across tiles, use only

    rho = max(max_l min(4,d_l), min(2,number of positive d_l)).

This is the same conservative rank rule for both tile widths. In
particular, this comparison does not add a special join for two
three-dimensional residual images.

Expand z^wt(y) over selected output-zero masks. Averaging potential masks
of total size j gives the upper moment

    K_j <= 1/binom(64,j) * sum_(sum a_l=j) sum_(v_l=0,...,g)
           product_l [binom(g,a_l) binom(g,v_l)
                      z^(g-v_l)(1-z)^v_l q^(-min(a_l,v_l))]
           * q^(-rho).

The implementation also caps K_j by q^(-min(j,4)), using the MDS property
of C. Omitting q^(-rho) gives the exact T_j. A positive dynamic program
retains only total potential count and the five possible rank states.
Multiplication by q^j during the calculation avoids floating underflow.

For r active outer rows, the same route-conditioned fractional bound is

    B_r = binom(8192,r) [beta^r z^(-838860)/(q-1)]^alpha
          * S_p^32767 T_p / c_r^256,

where beta=q^256/(q-1)^128, 0<alpha<=1, and

    S_p = sum_j binom(64,j) p^j(1-p)^(64-j) K_j^alpha,
    T_p = sum_j binom(64,j) p^j(1-p)^(64-j) T_j^alpha,
    c_r = binom(8192,r) p^r(1-p)^(8192-r).

The probability is over the coordinate scalars and the 256 independent
regional permutations. The bound unions all active-row sets and all
messages in this quiet, low-output-weight class. The initial state is zero;
the final successor state is unconstrained. This is not an all-word bound.

## Bounded comparison and directed replay

Both widths use the same 12 output markers and ten fractional exponents.
The output markers are 2^(-h) for h=0,1,2,4,6,8,10,12,14,16, together
with 2/(3(q-1)) and 133/(128(q-1)). The exponents are a/32 for
a=1,2,3,4,6,8,12,16,24,32. Only r=1024,2048,4096 is screened.

For each witness, the floating search optimizes log2(p/(1-p)) on [-16,24].
It rounds p to a rational with denominator 2^24. All six selected
witnesses are then replayed using positive Arb arithmetic at 160 bits.
The resulting logarithms are:

| Active rows r | FFT8 log2 bound | FFT16 log2 bound | FFT16 gain |
| ---: | ---: | ---: | ---: |
| 1024 | +7007.18521774 | +3855.30214552 | 3151.88307221 |
| 2048 | +54231.04366632 | +48760.42724914 | 5470.61641718 |
| 4096 | +76784.49990620 | +72148.67058058 | 4635.82932562 |

Positive values are uninformative probability upper bounds. They neither
certify the classes nor exhibit a low-distance codeword. All three FFT16
witnesses remain far above the acceptance threshold of -40.

## Decision and checks

FFT16 is algebraically compatible with the current design goals. Its
larger local branch number helps this quiet surrogate. The bounded
comparison does not justify changing the construction to obtain a
certificate: the remaining positive margins are too large, and no
nonquiet analysis was performed for FFT16.

The more useful next proof lever is to preserve tile occupancies through
the fractional power before changing tile width. The separate
[tile-conditioning calculation](HD_RANDOMIZED_OUTER_QUIET_TILE_CONDITIONING.md)
already measures a larger reduction in proof loss at some fixed witnesses.
A later FFT16 comparison should use that stronger proof interface on
both widths. No such additional search is included here.

The isolated helper and tests are
[theory/hd_randomized_outer_fft16_probe.py](theory/hd_randomized_outer_fft16_probe.py)
and
[theory/hd_randomized_outer_fft16_probe_tests.py](theory/hd_randomized_outer_fft16_probe_tests.py).
Five tests pass. They check all packet identities, the global Vandermonde
representation, 1156 actual tile-rank cases, 96 residual-line pairs,
agreement with the old FFT8 moment, and directed arithmetic.
