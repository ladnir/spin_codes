# Dual-MDS rank obstructions and a low-cost scalar repair

The unscaled dual-MDS inner has deterministic state-rank collapses at small allowed-output supports.
These invalidate an invertible-update shortcut, but do not constitute a bad-codeword or setup-failure lower bound.
A fixed emission scale outside GF16 removes every such deterministic collapse for every packet support.
The scale can be incorporated into the existing FFT with two additional GFNI128 products per packet, or one packed GFNI256 product.
The existing dual-MDS construction and its reference remain unchanged; the scaled map is a separate candidate requiring its own whole-code argument.

## Exact scalar equations and the causal involution

Use the AES field \(F=\mathrm{GF}(256)\), its embedded subfield \(H=\mathrm{GF}(16)\), and the reversal pairing \(R\) from [DUAL_MDS_PHASE.md](DUAL_MDS_PHASE.md).
Within a fixed regional orientation, write

\[
c(a)=v(a)=(1,a,a^2,a^3)^T,\qquad a(a)=v(a)^TR.
\]

The polynomial emitted by a state \(S\) is \(P_S(z)=v(z)^TRS\), and
\(a(z)c(w)=(z+w)^3\).
An input at label \(w\) adds its value times \((z+w)^3\) to this polynomial.

The packet identities \(Y_t=X_t+A_tQ_t\), \(Q_{t+1}=Q_t+C_tX_t\), and \(C_tA_t=0\) also give

\[
Q_{t+1}=Q_t+C_tY_t.
\]

Therefore the zero-initial, discarded-final input/output inner map is an involution.
Applying the same inner to \(Y\) reconstructs the same states and returns \(X\).
Equivalently, write the causal matrix as \(I+K\), with block \(K_{ij}=A_iC_j\) for \(j<i\).
Every summand in \((K^2)_{ij}\) contains \(C_\ell A_\ell=0\), so \(K^2=0\).
This remains true with different orientations in different regions.
It applies to the inner alone, not to the outer/route/diagonal composition, and not to the extended single-packet map with arbitrary initial state.

## The actual allowed-output update

After imposing zero outputs outside a packet support \(\mathcal J\), the state update in the common quotient is

\[
S'=F_{\mathcal J}S+
\sum_{j\in I\cap\mathcal J}c_jd_j\ell_j,
\qquad F_{\mathcal J}=I+\sum_{j\in\mathcal J}c_ja_j.
\]

This is the output-first interface in [REGIONAL_SPARSE_COVER.md](REGIONAL_SPARSE_COVER.md).
The following issues concern its deterministic first term, before the remaining fresh diagonals are exposed.

For \(\mathcal J=\{0,1\}\), \(F_{\mathcal J}\) has rank three and kills the state polynomial
\(f(z)=z^2+z+1\).
For \(\mathcal J=\mathrm{GF}(4)\subset H\), direct summation gives

\[
\sum_{u\in\mathcal J}v(u)v(u)^T=R+e_3e_3^T,
\qquad F_{\mathcal J}=e_3e_0^T.
\]

Thus an allowed-output quartet can reduce state rank by three without an exceptional diagonal value.
Translation conjugates the four affine GF4 cosets inside a packet, so all four have rank-one updates.

The exhaustive rank counts for small supports are:

| Allowed output size | Rank1 | Rank2 | Rank3 | Rank4 |
|---:|---:|---:|---:|---:|
| 0 | 0 | 0 | 0 | 1 |
| 1 | 0 | 0 | 0 | 16 |
| 2 | 0 | 0 | 24 | 96 |
| 3 | 0 | 16 | 0 | 544 |
| 4 | 4 | 0 | 192 | 1624 |

Among all 65,536 subsets, there are also 24 rank-one masks of size eight and four of size twelve.
No mask gives rank zero.
These counts hold in every phase and after regional similarity.

## Rank and even the exact root mask are not an exact state

Choose \(r\) outside the 64-label set and put \(g(z)=(z+r)f(z)\), with \(f(z)=z^2+z+1\).
The two one-dimensional formal state spaces generated by \(f\) and \(g\) have the same rank and exactly the same roots among all 64 labels.
Use allowed output support \(\mathcal J=\{0,1\}\), no input on those two coordinates, and input equal to the emission on all other coordinates.
Both examples have the same exact input support of size twelve and the same exact output support of size two.
There is no input/output overlap and hence no remaining fresh diagonal in this update.
Nevertheless, the \(f\) example returns to zero state, while the \(g\) example does not.

The replay uses AES byte \(r=16\); the common roots are bytes 188 and 189.
This is a local counterexample to an exact transition determined only by rank and the complete 64-label root mask.
It does not rule out a conservative upper operator on those summaries: such an operator must dominate both outcomes and keep its rank charges valid under the hidden dependence.

## A fixed scalar makes every allowed-output update invertible

Choose a fixed \(\eta\in F\setminus H\), for example AES byte 2.
Change only the emission:

\[
Y=X+\eta A S,\qquad S'=S+CX.
\]

The zero product, both MDS properties, and the causal involution are retained.
The output-first deterministic factor becomes

\[
F_{\mathcal J,\eta}=I+\eta\sum_{u\in\mathcal J}v(u)v(u)^TR.
\]

It is invertible for every subset \(\mathcal J\subset H\).
Here is an exact determinant proof.
Let

\[
\epsilon=|\mathcal J|\bmod2,\quad
x=\sum_{u\in\mathcal J}u,\quad
y=\sum_{u\in\mathcal J}u^3,\quad
z=\sum_{u\in\mathcal J}u^5.
\]

Frobenius identities give all remaining moments through degree six.
Expanding the four-by-four determinant yields

\[
\det F_{\mathcal J,\eta}
=(1+\eta p_1+\eta^2p_2)^2,
\]

\[
p_1=\epsilon y+x^3,\qquad
p_2=(\epsilon+1)(y^2+x^3y+x^6+xz).
\]

All roots of the polynomial \(1+Tp_1+T^2p_2\) lie in \(H\):

- If \(\epsilon=1\), the polynomial is constant or linear over \(H\).
- If \(\epsilon=0\) and \(x=0\), it is \((1+Ty)^2\).
- Otherwise \(p_1=x^3\ne0\). When \(p_2\ne0\), the quadratic splits precisely when \(\operatorname{Tr}_{H/\mathrm{GF}(2)}(p_2/p_1^2)=0\). In this case

\[
\frac{p_2}{p_1^2}
=\left(\frac{y}{x^3}\right)^2+\frac{y}{x^3}+1+\frac{z}{x^5}.
\]

The first two terms have zero trace.
The trace of one is zero because \([H:\mathrm{GF}(2)]=4\).
Every \(u^5\) lies in the GF4 subfield of \(H\), so \(z/x^5\) also lies in GF4 and has zero trace to GF2.
The case \(p_2=0\) is linear and needs no quadratic criterion.
Thus no \(\eta\notin H\) can make the determinant vanish.

For a translated phase, symplectic translation gives
\(F_{\beta+\mathcal J,\eta}=T_\beta F_{\mathcal J,\eta}T_\beta^{-1}\).
Regional orientation adds another similarity.
The same fixed \(\eta\) therefore works in every phase and every region.

The exhaustive replay independently eliminates the unscaled matrices for all 65,536 masks and checks the determinant identity.
It finds 66 distinct determinant quadratics and verifies that all 240 AES-field elements outside embedded GF16 avoid every root.

## What this repairs in a rank proof

For an actual nonzero incoming state, a return now requires \(I\cap\mathcal J\ne\varnothing\).
Without overlap, there is no fresh update and \(S'=F_{\mathcal J,\eta}S\ne0\).
The analogous formal-state statement is exact rank preservation after the zero-output equations whenever the overlap is empty.
The old deterministic rank loss of up to \(|\mathcal J|\) is absent.

With overlapping inputs, the fresh diagonal terms can still cause cancellations or rank changes.
Their dependence on the current state forms and on the same sampled diagonals must still be retained.
The scalar repair does not make rank alone an exact Markov state or provide a complete sparse transfer.
It supplies a uniform invertible first term for the finite-kernel analysis.
The previous one-row, dense-class, and dimension-only window arguments retain their stated scopes because their required structural hypotheses remain true.

## Cost in the existing FFT

A naive implementation scales all four state records before emission, costing one packed GFNI512 operation.
The six-product emission FFT permits a smaller change.
Its additive-basis state coordinates are denoted \(c_0,c_1,c_2,c_3\), and its first stage is

\[
u_0=c_0+s c_2,\quad u_1=c_1+s c_3,
\quad u_2=u_0+6c_2,\quad u_3=u_1+6c_3.
\]

The six denotes the embedded abstract GF16 constant; \(s\) varies across the SIMD lanes.
The final stage uses the existing offset multipliers on \(u_1,u_3\).
To scale every emission by \(\eta\), scale only \(c_0,c_1\), replace the first-stage constants \(s,6\) by \(\eta s,\eta6\), and leave the final-stage offsets unchanged.
This retains all six GFNI512 products and adds two GFNI128 products, which can be packed as one GFNI256 product.

The adjoint uses the matching transposed factorization.
Scale its first two scalar moments, and absorb \(\eta\) into the final four fixed-coefficient moment products.
Its additional multiplication count is the same.
The four-product phase translations and prepared regional boundaries do not change.

For the input-diagonal-inclusive GRS[32,22] profile, the leading volume changes from

\[
177/88\quad\text{to}\quad181/88\approx2.05682
\]

GFNI512 processed-byte equivalents per source symbol, an increase of about 2.26%.
The separate instruction estimates are \(169/88\) GFNI512 per source, the existing \(4/11\) GFNI128 per source for phases, and \(1/11\) GFNI256 per source for the packed new scales.
This excludes packing, shuffles, routing, and boundary corrections and is not a runtime estimate.
The fixed modified constants are prepared outside encoding; no general large-field data multiplication is introduced.
