# Power-of-two EBCH128 and RandomStepConv-M20 at 10.9%

## Result

This certificate uses one fixed extended BCH constituent in every outer row.
It adds no zero rows. The message and codeword lengths are exact powers of two:

\[
 k=2^{20},\qquad N=2^{21}.
\]

Let

\[
 D:=\left\lceil\frac{109N}{1000}\right\rceil=228590.
\]

The outward verifier proves

\[
 \Pr_\omega[d_{\min}(C_\omega)<D]
 <2^{-7.58436084118}.
 \tag{1}
\]

In particular, the setup failure probability is less than \(2^{-5}\).
Outside that event,

\[
 \frac{d_{\min}(C_\omega)}N
 \ge \frac{228590}{2097152}
 =0.10900020599365234\ldots>0.109.
\]

The theorem concerns RandomStepConv-M20. It does not establish the same
distance for RM2Sub.

## Construction and probability space

Set

\[
 B=128,\qquad K=64,\qquad L=16384.
\]

Split the message into \(L\) rows of 64 bits. Encode every row with the same
extended BCH \([128,64,22]\) code. The cyclic generator polynomial is
`0xf4845518b9582a1f`, and coordinate 127 is the extension-parity coordinate.
`FINITE_K20_EBCH128_OUTER_DEFINITION.md` fixes the complete coordinate
convention.

For every row, sample an independent uniform permutation of its 128 code
coordinates. For every coordinate region, independently sample a uniform
permutation of its \(L\) row positions. Concatenate the 128 permuted regions.

RandomStepConv-M20 starts with \(s_0=0\in\mathbb F_2^{20}\). At each input
position \(t\), sample an independent uniform binary \(21\)-by-\(21\) matrix
\(M_t\), and compute

\[
 (y_t,s_{t+1}):=M_t(x_t,s_t).
\]

The encoder emits \(y_t\) and discards the terminal state. The random setup
\(\omega\) contains all row permutations, region permutations, and matrices
\(M_t\). The encoder samples \(\omega\) once and reuses it for every message.
Probability in (1) is only over this setup.

## Tilted inner transfer

Fix \(z\in(0,1)\), and put

\[
 q_0:=2^{-20},\qquad b:=\frac{1+z}{2}.
\]

The two transfer states record whether the two convolution states agree.
For an input difference of zero or one, respectively, define

\[
 T_0=
 \begin{pmatrix}
 1&0\\ q_0b&(1-q_0)b
 \end{pmatrix},
 \qquad
 T_1=
 \begin{pmatrix}
 q_0b&(1-q_0)b\\ q_0b&(1-q_0)b
 \end{pmatrix}.
 \tag{2}
\]

For a fair candidate input, put \(C:=(T_0+T_1)/2\). Replacing an input one
by zero can only increase the tilted moment. This monotonicity justifies each
proof-only input deletion below.

## Outer-spectrum comparison

Let \(A_w\) be the imported exact BCH weight enumerator. Excluding the zero
and all-one words, define

\[
 \Gamma:=
 \max_{0<w<128}\frac{A_w2^{127}}{\binom{128}{w}},
 \qquad
 \Lambda:=\Gamma+1.
 \tag{3}
\]

The permuted counting measure of each nontrivial BCH row is bounded
pointwise by \(\Lambda\) times a uniform even row after one input deletion.
For \(Q\) active outer rows, the proof therefore charges

\[
 \binom{L}{Q}\Lambda^Q.
 \tag{4}
\]

Occupation \(Q=1\) instead uses the exact BCH spectrum. The relaxed distance
target makes the pointwise comparison in (3) affordable for larger
occupations.

## Occupation bounds

A uniform even row can be generated by choosing a uniform pivot coordinate,
sampling the other 127 bits independently, and fixing the pivot by parity.
The proof deletes the pivot input. The pivot is an auxiliary proof variable;
it is not part of the encoder.

The verifier separates four occupation ranges:

1. For \(Q=1\), it sums the exact BCH shells.
2. For \(2\le Q\le99\), it uses exact uniform-subset region coefficients.
3. For \(100\le Q\le16319\), it uses the dispersed-pivot coefficient bound.
4. For \(16320\le Q\le16384\), it uses the exact-complement recurrence below.

For the final range, write \(R:=L-Q\), so \(0\le R\le64\). If one region
receives \(m\) deleted pivots, it has \(R+m\) noncandidate positions. Define

\[
 S_h:=\binom Lh^{-1}[v^h](C+vT_0)^L.
 \tag{5}
\]

For any \(r>0\), positivity and the multinomial pivot law give

\[
 \mathbb E[z^W\mid Q]
 \le
 \frac{Q!}{128^Q}r^{-Q}
 e_0^{\mathsf T}
 \left(\sum_{m=0}^Q\frac{r^m}{m!}S_{R+m}\right)^{128}
 \mathbf 1.
 \tag{6}
\]

The verifier evaluates every coefficient in (5). Thus the outward receipt
does not use the analytic tail cap employed during witness search.

For each occupation, the verifier multiplies the conditional moment by (4)
and by the Chernoff factor \(z^{-D}\). It then sums the resulting bounds over
all \(Q\).

## Outward verification

The diagnostic files store every positive witness as a hexadecimal
binary64 value. The verifier treats each stored value as an exact dyadic
rational. Arb encloses logarithms, exponentials, and factorial expressions.
Every positive binary64 matrix operation is rounded toward positive infinity.

The verifier reports

\[
 \log_2\Pr_\omega[d_{\min}<D]
 <-7.584360841183562.
\]

Occupation one is dominant, with pointwise logarithmic bound
\(-7.585225198814789\). The receipt is

## Scope and remaining obligations

This is an information-theoretic certificate for a random linear inner.
It does not claim a compact setup or competitive implementation. A literal
setup stores one independent \(21\)-by-\(21\) binary matrix per input bit.

The verifier authenticates `scripts/EBCH128_64.wd` and checks its internal
mass, symmetry, parity, and minimum weight. It does not derive the enumerator
from the stated generator polynomial. The spectrum-to-generator binding
remains an explicit imported premise.

At the same 10.9% target, the nearest-arithmetic M19 analysis covers all
occupations with 0.759 bits of aggregate margin. That result is diagnostic,
not an outward certificate. A lower distance target may create enough sparse
margin to certify M19, but saving one memory bit is unlikely to justify a
large distance reduction.
