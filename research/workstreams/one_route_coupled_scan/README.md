The first command uses GF(16) over GF(2), with theta of degree four. It checks
local algebra exhaustively in small dimensions. It does not instantiate the
K20 outer, evaluate route probabilities, or benchmark encoding.
The second command checks the whole-state counting bridge in GF4/GF16,
including zero-source fibers, marker order, and joint weighting. It is
an exact toy check, not a finite K20 certificate.
The source-rank check tests local RS shortening, projected diagonal-rank
caps, and the top-column identity. For the directed finite gates and their
fixed rational markers, use the serial commands in the
[exact-route checkpoint](SMALL_STATE_EXACT_ROUTE_GATE.md#reproduce-serially).
The subsequent commands check exact arithmetic in the analytic obstructions,
necessary support masks,
small common-quotient fixtures, and pair-profile normalization. The source
module [coupled_rank_transfer.py](theory/coupled_rank_transfer.py) evaluates
local rational bounds; it does not implement a full K20 certificate.

The positive-envelope checker uses floating point only to propose its vector;
every claimed local inequality is then checked with exact fractions. The
one-group gate uses upward-rounded positive arithmetic at two precisions.
The older tau=256 check retains its failed 33-column screen as a checkpoint;
the newer checks close the classes listed above. The two-group check reports
its failed broad upper bound explicitly; the endpoint-aware check verifies
only the stated 33..35-column subclass. The separate `screen_sparse_gate.py`
requires NumPy and is only a floating-point diagnostic of the older relaxed
bound; it must not be used as a distance certificate.

The newer broad-gate diagnostics are `check_ranked_two_groups.py`,
`check_lazy_outer.py`, and `online_route.py`. The first two use directed
80/120-digit arithmetic and still report failed bounds. The online command
defaults to a floating-point screen; its combined lazy-outer use must meet
the exposure obligations in the linked notes. None is a whole-code check.
`screen_two_group_balance.py` separates source-dimension, threshold, and
regional costs at a few fixed markers; it is not an unrestricted search.
