# Riffle SpectrumPerm-TransposeBitShuffle-RandomStepConv

This folder studies the first replacement of a random constituent matrix by
a fixed outer code. Each outer block receives an independent coordinate
permutation. The construction then uses bit transpose and one-lap
RandomStepConv.

`GOAL_01.md` defines the initial spectrum experiment. The inner maps remain
random and will be replaced separately.
