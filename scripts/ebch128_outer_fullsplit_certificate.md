# Exact EBCH-128 block-outer certificate

Updated: 2026-08-08

This is a separate exact certificate lane for the finite full-split
construction.  Its ambient code replaces the direct sum of 4096
`RM(4,9) [512,256,32]` outer blocks by 16384 copies of the committed extended
BCH `[128,64,22]` weight enumerator.  The primary variant is an explicit
codimension-64 subcode obtained with one componentwise-XOR parity block.

- ambient `N=2^21`, `K=2^20`;
- parity-block variant `K'=2^20-64=1048512`;
- outer: 16384 extended BCH `[128,64,22]` blocks;
- inner: full-split extended BCH `[128,64,22]`, with `b=64`;
- target `d=floor(.09*N)=188743`.

The primary conclusion is therefore an explicit-outer binary
`[2^21,1048512,d_min >= 188744]` existence result with 41.29 theorem-safe
bits.  The unchanged ambient direct sum retains dimension `2^20` but only
20.80 theorem-safe bits.  Independently choosing a uniformly random
codimension-20 outer subcode gives dimension `1048556` and 40.80 bits, but it
does not have the parity variant's deterministic, encoding-friendly form.

## XOR-parity construction and GF(2^128) use

Split the input into 16383 blocks `m_i`, each containing 64 field symbols,
and set

```text
m_16384 = m_1 XOR m_2 XOR ... XOR m_16383
```

componentwise.  Encode all 16384 blocks with the same binary EBCH
`[128,64,22]` generator, interpreted over `GF(2^128)`.  This is an injective
codimension-64 subcode of the ambient direct sum.  Every nonzero input
activates at least two local blocks: a single active independent block is
repeated in the parity block, while two or more active independent blocks
already suffice even if their XOR vanishes.  Each active EBCH block has
weight at least 22, so the outer spectrum is zero below weight 44.  Above 44
it is coefficientwise bounded by the ambient spectrum because it is a
subcode.  These are exactly the two facts used by the refined union bound.

The binary distance theorem applies unchanged to field-symbol encoding.  In
an `F_2` basis of `GF(2^128)`, every field codeword decomposes into 128 binary
component codewords generated by the same binary matrix.  A nonzero field
codeword has a nonzero binary component, and that component's support is
contained in the field codeword's symbol support.  Scalar extension therefore
preserves the binary minimum-distance lower bound.  The result can equivalently
be read as a `GF(2^128)`-linear `[2^21,1048512,d_min >= 188744]` symbol code.

Encoding the parity block uses 64 running 128-bit XOR accumulators (1 KiB) and
`16383*64=1048512` field additions.  It requires no field multiplication or
coefficient table, can be fused into the pass over input symbols, and leaves
the number of local EBCH encodings at 16384.

The initially positive bounds for the critical and post-prefix windows were
pole-choice slack.  After rational pole retuning, the limiting post-prefix
component is the exact `h=501..2000` cap at `-53.424193575894`; the limiting
overall component is the exact/outward `h<=500` family.

The ambient low-weight improvement subdivides the first 4000-block gap bucket
into 250-block rational subbuckets for weights through 150.  For the parity
variant, the exact weight-44 floor is applied first and that refinement is
extended through weight 300.  Its first bucket falls to `-52.879612877898`;
the exact ultra-late sum at `-41.310535563995` becomes the bottleneck.

## Why the ambient full-dimension ensemble cannot reach 40 bits

The artifact also contains a lower-bound audit.  The weight-22 outer words
whose permuted support lies in the final 4000 inner blocks have placement
expectation `2^-34.858313...`.  Conditional on this event, the expected output
weight is at most 4000 times the exact per-live-block mean.  Markov's
inequality gives conditional probability at least `0.321832747...` that the
output weight is at most 188743.  Consequently this family alone contributes
more than `2^-36.493931` to the actual first moment.

Therefore no upper-bound cleanup can give the unchanged full-dimension,
uniform-interleaver ensemble 40 bits.  The parity-block and random-subcode
results are genuine code changes, not merely more favorable reporting.

input artifacts by SHA-256.  As in the existing RM/EBCH theorem lane, the
mathematical provenance of the committed EBCH weight enumerator is a declared
input: this certificate validates and consumes that table but does not derive
the enumerator from a generator polynomial.
