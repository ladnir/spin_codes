# Script Notes

The Python files in this directory are source artifacts: verifiers, evaluators,
diagnostics, and exploratory proof tools.  Generated CSV/PNG outputs and Python
bytecode are ignored by default; force-add a generated artifact only when it is
promoted into a result lock, manifest, or paper-facing certificate.

The current paper-facing verification entry points are recorded in
`RESULTS_LOCK.md` and `PAPER_RESTRUCTURE_PLAN.md`.
